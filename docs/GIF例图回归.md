## 1. 新增

- `eval/gifs/truth.json`：12 条真值，每条含 `expected_jumps`、`duration_ms`、`beats`（时刻 + 容差）与全帧描述；jump 另有 `verified_jumps`（逐帧确认的切点）与 `known_false_jumps`（逐帧确认的误报帧号）。
- `tools/gifcheck.py`：不约读图方、不花 token 的结构回归。

  - 代表帧两两 NCC ≥0.90 的重复对

  - `beats` 覆盖（每个时刻 ±tol 内有没有代表帧）

  - 用法：`python tools/gifcheck.py`（复用产物）/ `--refresh`（12 个重跑，约 45s）/ `--strict`（结构硬伤返回 1）/ `--strict-jumps`（新误报与漏切点返回 1；已知误报不罚）

## 2. 改了什么

`gif_digest.py` 的选帧层，四条：

1. **去重与末态保证从 >8s 下放到所有输入。** 12 个 GIF 里 86C6/AFF4/C3AC 有 ≥0.90 的重复格，381C/7FEB/83B7/eef3 的末态没有图；短片段此前为了冻结 9 段基线一直没启用。**这条改动会让 9 段 ≤8s 的代表帧变化**：拿 `git show a84e452:gif_digest.py` 重跑，7/9 段变了（e1/e3/e4/e5/e6/e8/e9；e4 4→2、e5 4→1）。旧的 9/9 读数是 76c3839 之前的产物，**不能直接套用**；重测读数见 `docs/交接.md` 的复核块。
2. **传递重复消解。** 旧 `_drop_same_picture` 一趟贪心：A≈B、B≈C 时替换 B 后 A/C 仍可能同时留下（86C6 的 36/49 是 0.942）。改成反复消解冲突，直到没有一对 ≥0.90。
3. **末态让位有选择规则。** 旧实现让优先级最低的非切点格——381C 用「挥手」换末帧、EEEC 用「暗场」换末帧、eef3 用「两人同框」换末帧，都是拿唯一状态换尾图。新 `_tail_drop_candidate`：
   - 保护最早的代表帧（开场状态，且在前 40% 内）；
   - 优先让「和邻居挤在一起」的那格（≤10% 时长），其次让优先级最低的；
   - 长片段（>8s）额外保护切点前后对照对，避免 L2 的 1.81s 再被让掉。
4. **短片段尾段有 jump 时也允许末帧。** GIF 的 jump 多是快动作，末帧往往就是最后一个可读状态；长片段保持原规则（尾段有硬切时不抢末帧）。

`tools/test_budget.py` 从 9 组扩到 11 组：新增「传递重复」与「末态让位（保护开场 / 相邻假切点对 / 长片段保护对照对）」；短片段测试改名为预算测试（实出张数可少于 k，`budget.images` 如实写）。

## 4. 快动作 vs 切点：真值先错了

2026-11-08 把当时那 15 处「假 jump」逐帧核完（前后各 1 帧；两处判不准的取 ±2 帧）：**7 处是真切点，9 处是真误报**。

| 文件 | 报的帧 | 逐帧结论 |
|---|---|---|
| 39EC ×5 | 94 / 174 / 185 / 187 / 199 | 全是狗尾巴草横掠镜头，背景蓝墙一格没动 → 误报 |
| 381C ×1 | 46 | 44–48 帧连续走远，无断帧 → 误报 |
| 7FEB ×3 | 3 / 60 / 82 | #3 运动模糊、#60 原地转身 → 误报；**#82 人物放大一倍 + 背景换色 → 真切** |
| 83B7 ×3 | 51 / 84 / 95 | #51 前后几乎同图 → 误报；**#84、#95 全身张臂 → 半身近景 → 真切** |
| eef3 ×3 | 52 / 57 / 62 | **窗框与散景在同一条跳帧上换掉 → 三处都真切** |

所以「15 处全是同一场景里的快动作」这句是错的——真值是照首版读图写的，而首版本身没看见那 3 段里的机位切。现在真值分 `verified_jumps` / `known_false_jumps` 两类，`gifcheck` 只对**新误报**与**漏切点**报警。

**下一步的判据线索：差别在背景，不在主体。** 9 处误报的背景（蓝墙、马路、街景）在跳帧上没动；7 处真切点的背景同时换了。所以该做的是「只测背景区」的相似度——取前后各 N 帧里能量最低的环带（或整幅低运动区域）做掩膜，在掩膜上算 NCC / 颜色直方图，而不是继续在整幅统计上换阈值。之前试过的三条（邻域 NCC、跨 2 帧 NCC、直方图回归）都是**整幅**统计，在真切点上自然会被主体运动带偏；这条线索对应交接的待办 2，验证集就是这 12 段。

旧的失败记录留在这里当参照：整幅统计下，邻域相邻对 NCC 真切点 0.88–1.00 / 假切点 0.58–0.93；跨 2 帧 NCC 真切点 ≈ 本对值 / 假切点 0.17–0.89；直方图回归 e7 闪白 1.16、e8 模糊切 1.51、e9 推镜假切 1.30——三个区间都重叠，调阈值解决不了。
