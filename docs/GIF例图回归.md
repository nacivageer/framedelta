# GIF 例图回归（2026-11-08）

来源：`H:\DSH\给dsh看的动图` 的 12 个动图；全帧结论来自 `Daily Chat/notes/识图库.md` 第 3 条（同一批文件，已实看）。这条线只做两件事：**把它变成可复跑的回归集**，以及**修掉 ≤8s 也能看见的选帧硬伤**。渐变判据不在这里（由另一条会话做，见 `docs/方案_渐变判据.md`）。

## 1. 新增

- `eval/gifs/truth.json`：12 条真值，每条含 `expected_jumps`、`duration_ms`、`beats`（时刻 + 容差）与全帧描述。
- `tools/gifcheck.py`：不约读图方、不花 token 的结构回归。
  - `jump` 与 `expected_jumps` 的差（假 jump）
  - 代表帧两两 NCC ≥0.90 的重复对
  - 首/末覆盖与最大空档（末帧同图不算漏）
  - `beats` 覆盖（每个时刻 ±tol 内有没有代表帧）
  - `budget.images` 与 `budget.k`
  - 用法：`python tools/gifcheck.py`（复用产物）/ `--refresh`（12 个重跑，约 45s）/ `--strict`（结构硬伤返回 1）/ `--strict-jumps`（把已知假 jump 也当失败）

## 2. 改了什么

`gif_digest.py` 的选帧层，四条：

1. **去重与末态保证从 >8s 下放到所有输入。** 12 个 GIF 里 86C6/AFF4/C3AC 有 ≥0.90 的重复格，381C/7FEB/83B7/eef3 的末态没有图；短片段此前为了冻结 9 段基线一直没启用。实测 9 段短素材的 `key_frames` **逐段不变**，基线 9/9 仍有效。
2. **传递重复消解。** 旧 `_drop_same_picture` 一趟贪心：A≈B、B≈C 时替换 B 后 A/C 仍可能同时留下（86C6 的 36/49 是 0.942）。改成反复消解冲突，直到没有一对 ≥0.90。
3. **末态让位有选择规则。** 旧实现让优先级最低的非切点格——381C 用「挥手」换末帧、EEEC 用「暗场」换末帧、eef3 用「两人同框」换末帧，都是拿唯一状态换尾图。新 `_tail_drop_candidate`：
   - 保护最早的代表帧（开场状态，且在前 40% 内）；
   - 优先让「和邻居挤在一起」的那格（≤10% 时长），其次让优先级最低的；
   - 长片段（>8s）额外保护切点前后对照对，避免 L2 的 1.81s 再被让掉。
4. **短片段尾段有 jump 时也允许末帧。** GIF 的 jump 多是快动作，末帧往往就是最后一个可读状态；长片段保持原规则（尾段有硬切时不抢末帧）。

`tools/test_budget.py` 从 9 组扩到 11 组：新增「传递重复」与「末态让位（保护开场 / 相邻假切点对 / 长片段保护对照对）」；短片段测试改名为预算测试（实出张数可少于 k，`budget.images` 如实写）。

## 4. 没解决的：快动作 vs 切点

15 处假 jump 全是「一个连续场景里的快动作」，抽帧确认没有换场。试过三条判据，在真切点上都有重叠：

- 邻域相邻对 NCC（切点两侧应稳定）：标定真切点 0.88–1.00，GIF 假切点 0.58–0.93；
- 跨 2 帧 NCC（快动作会回到原画面）：真切点 ≈ 本对值，假切点 0.17–0.89，区间重叠；
- 颜色直方图跨帧回归（真切点颜色永久改变）：e7 闪白 1.16、e8 模糊切 1.51，e9 推镜假切 1.30，仍重叠。

结论：不是调阈值能解决的；需要换表示法（长滞后场景身份 / 局部特征匹配），或接受「只报 jump + 证据，让读图方判」。当前 `gifcheck` 把假 jump 单独计，不混进结构硬伤；`--strict-jumps` 留给将来修好后再接。
