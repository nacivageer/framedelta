# 方案：#2 溶解 / 渐变事件的判据

2026-11-08。目标只有一个：让 digest 能报出「画面怎么变过去的」这类**没有硬切**的状态切换，并把时刻报准（读图方的 ±0.5s 靠它）。

## 0. 结论先说

- 现在 `drifts` 有**两道闸**，恰好各挡掉一半：`hsv ≥ 4`（低对比叠化的逐对分数只有 1–2）、「前后 0.13s 安静」（落在运动里的溶解）。4 个漏点里 2 个死在第一道、2 个死在第二道。
- 强度 / 位移 / 调色板这几类「单帧特征」**分不开溶解与运镜**（下面有实测），别在这条路上继续调阈值。
- 可靠的信号只有两个：**累计变化**（0.2–0.3 的像素在 0.4–0.9s 内变了）与**亮度塌陷**（到白/黑场）。
- 建议把判据从「尖峰检测」改成**状态分段**：先分「在变 / 不变」，再判断两个稳定态之间是否有一次过渡。新增事件类 `fades`，**只对 >5s 的输入启用**（≤5s 的 9 段短素材现在 9/9，不动它）。
- 预期：4 个漏点补上 3 个（L1 11.1、L2 14.72、L3 6.55），L1 14.2 仍是已知漏点。工具自报 11/16 → 14/16；读数（现在 12/16）目标 13–15/16。

## 1. 现状：4 个漏点各死在哪

`content_events()` 的 drift：把 `hsv ∈ [4, 18)` 的连续对攒成 run（≥5 对），要求 run 前后各 4 对的能量中位数 < 3.0，再用首尾帧的 `changed_frac ≥ 0.20` 确认。

实测（`runs/fix2/k6/<case>/flow.csv`，窗口取真值点 ±0.4s）：

| 漏点 | 对数 | hsv 中位 | energy 中位 | local_frac | \|dx\| | resid | 首尾 Δ | 死在 |
|---|---|---|---|---|---|---|---|---|
| L1 11.1 片名卡→花海 | 28 | **1.2** | 1.0 | 0.00 | 0.0 | 0.1 | 0.27 | `hsv ≥ 4` |
| L1 14.2 女子→骑兵 | 23 | 6.1 | 7.2 | 0.20 | 0.5 | 0.8 | 0.77 | 前后不安静 |
| L2 14.72 →白屏 | 12 | 5.1 | 11.9 | 0.33 | 0.5 | 1.0 | 0.96 | 前后不安静 |
| L3 6.55 换页 | 17 | **0.8** | 0.6 | 0.00 | 0.0 | 0.0 | 0.32 | `hsv ≥ 4` |

`counts.drifts`：L1 = 0、L2 = 0、L3 = 1（只抓到 6.27–6.44 的窗口收起，即真值 6.4 那次）。所以不是阈值松紧，是这两道闸本身把溶解定义在外了。

## 2. 试过、且失败的三条路（别再走）

1. **相位相关对齐，扣掉运动解释得掉的部分**。对每个窗口取首尾帧，按 `phase_shift` 平移后重算变化：溶解的残余应远大于运镜。实测 explain ≈ 0（溶解 0.00 / 0.01，运镜 −0.07 / −0.04）——0.5s 滞后的位移（10–37px）已经超出「纯平移」能解释的范围，滚动填充还引入了假的差异。**失败。**
2. **局部基线尖峰**（C(i) = 帧 i 与 i+L 的变化占比，基线取 ±1.5s 中位数、排除 jump 邻域）。L1 在爆闪区一次冒出 5 个假阳（4.59 / 5.35 / 6.04 / 8.51 / 12.61），**同时仍然漏 11.1**——因为 11.1 的 C 在灰度 256 宽上只有 0.15 左右，够不到 0.18。**失败。**
3. **全局调色板位移**（首尾帧的 luma / mean RGB / 色相直方图距离）。L1 14.2 的 ΔRGB 21.5、ΔH 0.45，而「打斗运镜」对照是 22.7 / 0.25——**同值，不可分**。唯一分得开的是白场（L2 的 Δluma +116、Δstd −14，运镜最大 +20、+2）。**只对白场有效。**

结论：单帧或单窗口的强度统计没有「溶解 vs 运镜」的判别力；判别力只存在于**时间结构**里——溶解是「稳定 → 过渡 → 稳定」，运镜是「一直在变」。

## 3. 判据设计：状态分段

### 3.1 分段

在分析分辨率上，把每对分类成两种状态（沿用现有 pair 字段，不新增测量）：

- `quiet`：`energy < still_energy` 且 `changed_frac < still_changed_frac`（沿用现有判据），**或** 与前一对的累计差 < 1%。
- `changing`：其余（含 motion / subtle / jump）。

把连续的 `changing` 对合成**变化段** `[f0, f1]`。段的两端向外要求至少有 `min_quiet_ms = 250ms` 的 `quiet`（否则这段不算「有边界」，跳过——运动素材里绝大多数是这样的段，天然不出事件）。

### 3.2 两条触发

段 `[f0, f1]`，两侧静段取各 250ms 的窗口 `A`（段前）与 `B`（段后）：

- **渐变（mode = gradual）**：`C(A→B) ≥ 0.18`（两侧画面的差异像素占比）且 `120ms ≤ 段长 ≤ 1200ms` 且段内没有 jump（有 jump 已由 `jumps`/`transitions` 报过）。
- **塌陷（mode = blank）**：`|luma(B) − luma(A)| ≥ 60` 且（`luma(B) ≥ 235` 或 `luma(B) ≤ 20`）且段长 ≤ 600ms。**不要求**两侧都静（白场常常接在推近后面）。

两条都命中时只报一条，`mode = "blank"`。

### 3.3 报告

- 时间取**变化段中点** `mid_ms = (start + end) / 2`——与真值的写法一致（真值就是「溶解记在新画面首次稳定可见，取中点」）。
- 同时给 `start_ms / end_ms / duration_ms`，读图方据区间长度判断「是渐变不是硬切」。
- 证据字段：`changed_frac`（A→B）、`luma_a / luma_b`、`pairs`、`max_pair_frac`、`jump_inside`（应为 0）。

### 3.4 阈值初值（都在下面第 5 步校准）

| 参数 | 初值 | 依据 |
|---|---|---|
| `fade_min_quiet_ms` | 250 | L3 的 5.94–6.24 静段只有 300ms，再长就漏 |
| `fade_seg_min_ms` / `max_ms` | 120 / 1200 | 4 个漏点分别是 600 / 550 / 130 / 150ms |
| `fade_changed_frac` | 0.18 | 4 个漏点 A→B 是 0.21–0.96 |
| `fade_blank_luma` | 60 | 运镜最大 20，白场 116 |
| `fade_blank_level` | 235 / 20 | 白屏实测 238.7 |

### 3.5 作用范围

`total_ms > 5000` 才启用（与 `_COARSEN_MIN_TOTAL_MS` 同一条线）。≤5s 的 9 段短素材产物保持一字不变，`9/9` 的基线继续有效；短素材上的溶解（e3_a）本来就已经读对了，不需要新事件去改变它。

## 5. 验证计划（四级，前一级不过不进下一级）

1. **单测**（`tools/test_fades.py`，合成 pairs，秒级）：静-变-静的分段边界、`min_quiet` 门槛、jump 段被抑制、时间取中点、`>5s` 的开关。
2. **结构**：3 段长样本重跑，看 4 个漏点补上几个（目标 3 个）；同时 `tools/eval_run.py` 跑 9 段短素材，产物指纹必须「变了 0 段」。
3. **工具自报基线**：`answers_tool_long.json` 重算，11/16 → 目标 14/16；同时看**多报**有没有增加（现在 L1 有 2 处多报：5.8 / 9.9）。
4. **读数**：3 段各一个新读图方（k=6、代理不看真值），目标 ≥14/16 且次数一致 ≥2/3。这一级不过，就把结论记成「渐变不在内容统计的可分范围内」，不再加阈值。

## 6. 风险与已知限制

- **L1 14.2 大概率仍漏**：溶解两边都不是稳定态（左侧是推近、右侧是下摇）。要抓它需要「场景身份」类特征（局部特征点匹配率、语义），成本高、样本只有 1 处，这一轮不做，写进已知限制。
- **L3 的 6.4 与 6.55 可能并成一次**（面板消失与换页只隔 150ms）：并了就是 1 个命中而不是 2 个，可接受，但要在结果里写清。
- **运动素材几乎没有静段**：快剪、动作片这类「一直在动」的长素材不会出 fades——这是安全方向（宁可漏报），但要接受「动作片里的溶解抓不到」。
- 阈值仍在 3 段 15 秒上定，样本小；换语料（真人、长视频）要重跑第 2、3 级。

## 7. 工作量

- 代码：`fade_events()` ≈ 80 行（复用 `grays` 与现有 pair 字段）+ digest/meta 字段 + 单测 ≈ 40 行。
- 跑数：3 段长样本各 30s，9 段短样本各 5s，合起来约 2 分钟。
- 读数：3 个读图方，约 10k token。
- 一轮内能给结论；若第 4 级不涨，就按第 5 步写「不可分」收尾，不再扩大改动。

| L3 6.55 换页 | 已被 drift 覆盖（6.27–6.44） | 重叠的 fade 按规则不重复报，6.4 那一次命中 |
| L1 11.1 | **没检出** | 见下 |
| L1 14.2 | **没检出** | 见下 |

**读数**：k=6 的 3 段由 12/16 到 **13/16**（L2 5/6 → 6/6），次数完全一致 2/3。

**L1 为什么抓不到（抽帧核对，方案的前提被推翻）**：11.1 不是「静 → 溶解 → 静」，而是**标题文字在一个一直在缓慢运动的实拍底片上淡出**——`tools/frames.py` 抽 #320 / #330 / #340 / #350 四帧，文字渐隐的同时底下的蓝花石阶、栈道一直在动；逐对 `changed_frac` 只有 0.008–0.010、`hsv` 1–2，而累计 200ms 就有 5–7%（底片在动），所以「两侧静段」这个入口条件不成立。14.2 同理，是两张实拍镜头之间的叠化。

这类要另开判据（区域级文字/图层变化，或场景身份特征），本轮不做；已知限制写进交接。

## 9. 后续：区域级 / 场景身份两路也分不开（2026-11-09，D 节）

按上面的「另开判据」又测了一轮，结论是**不做**。方法与数字见 `docs/决策记录.md`「溶解判据（不可分）」一节，这里只记结论：

- 测量工具 `tools/measure_dissolve.py`，2 个正样本窗对 **523 个负样本窗**（同素材里除真值外的全部 0.6/0.7s 滑窗）。
- 五族统计（区域低分格 / 端点混合 / 直方图轨迹 / 细节塌陷 / 场景身份）里，两处正样本都落在负分布中间（分位 16%–78%），没有一族能把它们和爆炸、刀光、运镜分开。
- 11.1 的难处是文字只贡献 7% 的高频能量；14.2 的难处是两端镜头都在动，中点既不在端点连线上、也不够「不像两端」（最佳平移 NCC 仍有 0.71）。
- 真要做得上局部特征（SIFT/ORB）或文字掩膜，并至少凑 8–10 处不同类型的溶解样本。**不要再给 `fade_events` 加阈值**——它服务的是「有稳定边界」的渐变，这两处恰好没有。
